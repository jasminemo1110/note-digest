# Note Digest

在 Obsidian 原文旁读懂英文，留下语境中的词语和金句。

独立的 Obsidian 桌面插件，V1 面向 Markdown 英文文章，以中文提供翻译与语境解释。当前处于开发阶段，功能状态见[路线图](docs/ROADMAP.md)。

## 当前开发版

当前版本 **0.2.3 开发版**。已支持选区翻译、完整语境解释（音标和纠错）、主动插入译文，以及词语/金句收藏：原文末尾、独立学习笔记、两者都保存。独立笔记位于 `Digest/文章学习/`，按来源汇总；文件名附来源 ID，避免同名文章冲突。

收藏后普通段落在阅读视图自动高亮；侧栏“本文收藏”可定位原文、打开学习笔记、取消收藏高亮。“取消收藏高亮”不会删除已经写入的笔记；新增“取消高亮并删除笔记”会检查文末和独立笔记，仅删除对应收藏卡片，保留原文章、其他卡片和笔记文件。重复保存保留现有卡片及用户手工编辑，不会用新 AI 解释覆盖旧记录。

0.1.0 的选词、翻译与插入已由用户实际验证。0.2.0 的收藏及定位流程已由用户反馈验证。0.2.3 的 63 项自动测试、侧栏 DOM 测试与构建通过；删除操作尚需实际 Obsidian 验证。

边界：高亮只处理能精确对应的普通段落；复杂 Markdown 或变化/歧义段落跳过。源文档改名在插件运行期间跟踪，插件关闭期间的移动恢复尚未实现。永久插入译文仍限普通单行段落。

已提供所选文本的 Summarize（最多 12,000 字符）。尚未实现：覆盖整篇文章的分节摘要、按节/全文翻译和原位双语阅读层。

### 收藏用法

1. 选中短词句点击 Digest 或按 D，自动显示英文及中文；长选区（超过 400 字符或跨空行段落）先显示操作栏，不发请求。
2. 长选区可点击 Summarize 获取所选内容摘要，或点击翻译按原文段落呈现英中对照。语境解释显示详细卡片。
3. “添加到原文下方”“添加到句后括号”仅在翻译模式、每段中文后出现；语境解释和摘要中不出现。
4. 保存位置默认“末尾及独立笔记”，可改为“只有末尾”或“只有独立学习笔记”，统一点击“保存”。语境解释默认保存完整单词卡片，也可选“金句与译文”。翻译模式保存为金句。
5. 阅读视图选中文字后按 N，会翻译并保存金句到末尾及独立笔记；这与新版默认保存位置一致。编辑器、输入框、输入法组合、修饰键或长按不会触发单字母操作。也可通过命令面板或自定义组合快捷键使用。
6. 自然/有效口语表达省略判断模块；错误、不自然表达显示原因与建议改法。语境不足时保留不确定性提示，不编造改法。
7. 新学习笔记与“本文收藏”均区分“单词”“金句”。旧卡片可点击“整理旧版卡片并分组”，只有与旧版输出完全匹配的内容会迁移；手工改动保留。独立学习笔记只在顶部保留一次来源链接。
8. “取消高亮并删除笔记”按记录标记定位，不按单词全文删除。已取消高亮但保留笔记的条目仍可清理；部分失败时显示原因并保留重试入口。新卡片有起止边界，明确属于卡片内部的改动会随卡片删除；旧版无结束边界且手工修改过的卡片会保留，提示手动处理。
9. 仅查看翻译、解释或摘要不会创建学习笔记。段落翻译失败或被新操作取代时，不把未完成结果作为完整翻译保存。


## 目标体验

- 选中英文，点击 Digest 或使用命令，在右侧学习栏查看翻译与解释。
- 翻译默认只用于当前阅读；可主动插到原文下方或句后括号中。
- 收藏词语和金句到原文末尾、独立学习笔记，或同时保存；已收藏内容在原文高亮。
- 长文可先 Summarize，再按摘要小节翻译；也可直接翻译本节或全文。
- Digest 文件夹可保存每篇文章的词语、金句及完整双语笔记。

## 开发

需要 Node.js 20+。

```sh
npm ci
npm test
npm run build
```

构建产物为 `main.js`。将 `main.js`、`manifest.json`、`styles.css` 复制到测试仓库的 `.obsidian/plugins/note-digest/`，在 Obsidian 中启用社区插件。先用示例仓库测试，不要直接安装到重要笔记仓库。

启用后在设置中选择密钥；选中英文点击 Digest，或从命令面板执行 Note Digest: Digest 选中内容。可在 Obsidian 快捷键设置中给该命令分配快捷键。右侧“语境解释”会另发请求；写入按钮明确修改原文。当前仅支持普通单行段落写入，复杂 Markdown 请先在侧栏阅读。

最低 Obsidian 版本见 manifest；使用系统 SecretStorage 选择 DeepSeek 密钥，插件只保存密钥名称。只有主动请求时才发送所选文本和必要上下文。
