# Note Digest

**在 Obsidian 原文旁读懂英文，留下语境中的词语和金句。**

Note Digest 是一款独立的 Obsidian 桌面插件。打开仓库里的英文 Markdown 文章，就可以在右侧栏查看中文翻译、结合上下文理解表达，并把值得留下的单词和金句直接保存为学习笔记。当前版本为 **0.2.4 开发版**，支持英文 → 简体中文，采用 [MIT 许可证](LICENSE)。

## 安装

目前尚未上架 Obsidian 社区插件目录，也未提供预编译安装包，需要从源码构建。需要 **Obsidian 桌面版 1.11.5 或更新版本**、**Node.js 20+（含 npm）**；通过命令克隆时还需要 Git。建议先在测试仓库体验。

### 让 AI Agent 帮你安装

可以把仓库链接和下面这段话交给能够操作本地文件、运行终端的 AI Agent，例如 Codex 或 Claude Code：


普通聊天窗口如果不能访问你的电脑，就无法代为安装；也可以按下面的步骤手动完成。

### 手动安装

```bash
git clone https://github.com/jasminemo1110/note-digest.git
cd note-digest
npm ci
npm test
npm run build
```

然后：

1. 找到你要使用的 Obsidian 仓库文件夹；这是存放 Markdown 笔记的目录，不是 Obsidian 应用程序目录。
2. 在仓库内创建 `.obsidian/plugins/note-digest/` 文件夹。`.obsidian` 是隐藏目录，需要在文件管理器中显示隐藏文件。
3. 将构建后的 `main.js`，以及项目根目录的 `manifest.json`、`styles.css` 复制进去。
4. 打开 Obsidian，在**设置 → 第三方插件 / 社区插件**中允许使用社区插件，找到并启用 **Note Digest**。如果列表未刷新，重启 Obsidian。
5. 按下方说明配置 DeepSeek API Key，再打开一篇英文 Markdown 文章开始使用。

更新时先关闭 Note Digest，更新源码并重新构建，再替换上述三个文件，最后重新启用插件。不要删除插件目录里的 `data.json`，其中保存着收藏记录和设置。

## 配置 DeepSeek API Key

Note Digest 当前使用 DeepSeek，需要你自己的 **API Key**。API 调用可能产生费用，请在 DeepSeek 平台查看账户额度与用量。

1. 登录 [DeepSeek 开放平台的 API Keys 页面](https://platform.deepseek.com/api_keys)，创建一个 API Key。可参考 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/api/deepseek-api/)。
2. 打开 Obsidian **设置 → Keychain（密钥链）**，新增一条密钥，取一个方便识别的名称，例如 `deepseek`，将 API Key 填入密钥值并保存。
3. 打开 **设置 → Note Digest**，在 **DeepSeek API Key** 一项中选择刚才保存的密钥。插件使用 Obsidian 的 SecretStorage，只记录密钥名称，不把真实 Key 写入插件的 `data.json`。
4. 打开一篇英文文章，选中一个词并点击 **Digest**。右侧出现中文翻译后，就可以继续点击**语境解释**。

如果提示缺少密钥，请检查 Note Digest 是否选择了正确的密钥；如果提示无权限或额度不足，请检查 DeepSeek 账户和 API Key。不要把 Key 发给 AI Agent、粘贴到 Issue、提交进 Git，或拍进截图。

## 为什么做 Note Digest？

已经存在 Obsidian 里的文章，可以在阅读时直接变成学习材料，无需先搬到浏览器，再导出、导入一遍：

- **阅读不中断**：在原文选词或选句，右侧立即提供翻译入口，并可进一步查看语境解释。
- **学到具体用法**：解释包含音标、当前语境中的含义、用法和双语例句；表达有问题时说明原因并给出建议改法。
- **临时查看或主动留下**：只看翻译不会改动笔记；需要时才把译文放到原文下方或句后括号里。
- **整张解释一起保存**：收藏单词时保留完整解释，金句保留原句和译文，学习区按单词与金句分类。
- **保存到自己的仓库**：可以写到原文末尾、独立学习笔记，或者两者都保存，不需要另外导出 Markdown。
- **回到具体语境**：已收藏内容可在支持的原文段落中高亮，并从侧栏定位来源；同一词在不同语境中分别保留。

## 使用方法

1. 选中短词句点击 Digest 或按 D，自动显示英文及中文；长选区（超过 400 字符或跨空行段落）先显示操作栏，不发请求。
2. 长选区可点击 Summarize 获取所选内容摘要，或点击翻译按原文段落呈现英中对照。语境解释显示详细卡片。
3. “添加到原文下方”“添加到句后括号”仅在翻译模式、每段中文后出现；语境解释和摘要中不出现。单词/单段选区插入译文成功后，可直接继续语境解释，无需重新 Digest。仅对插件确认的插入更新快照，手工修改仍需重新选择；同一译文不会重复插入。多段选区内部插入会改变选区连续性，仍需重新选择。
4. 保存位置默认“末尾及独立笔记”，可改为“只有末尾”或“只有独立学习笔记”，统一点击“保存”。语境解释默认保存完整单词卡片，也可选“金句与译文”。翻译模式保存为金句。
5. 阅读视图选中文字后按 N，会翻译并保存金句到末尾及独立笔记；这与新版默认保存位置一致。编辑器、输入框、输入法组合、修饰键或长按不会触发单字母操作。也可通过命令面板或自定义组合快捷键使用。
6. 自然/有效口语表达省略判断模块；错误、不自然表达显示原因与建议改法。语境不足时保留不确定性提示，不编造改法。
7. 新学习笔记与“本文收藏”均区分“单词”“金句”。旧卡片可点击“整理旧版卡片并分组”，只有与旧版输出完全匹配的内容会迁移；手工改动保留。独立学习笔记只在顶部保留一次来源链接。
8. “取消高亮并删除笔记”按记录标记定位，不按单词全文删除。已取消高亮但保留笔记的条目仍可清理；部分失败时显示原因并保留重试入口。新卡片有起止边界，明确属于卡片内部的改动会随卡片删除；旧版无结束边界且手工修改过的卡片会保留，提示手动处理。
9. 仅查看翻译、解释或摘要不会创建学习笔记。段落翻译失败或被新操作取代时，不把未完成结果作为完整翻译保存。

独立学习笔记默认放在 `Digest/文章学习/`，按文章汇总；文件名附有来源 ID，避免同名文章冲突。重复保存不会用新 AI 结果覆盖已有学习卡片或手工修改。

### 快捷键与入口

| 操作 | 入口 |
| --- | --- |
| 翻译选中的词句 | 悬浮的 Digest 按钮；阅读视图选中文字后按 `D` |
| 查看完整词语解释 | 右侧栏的“语境解释” |
| 快速收藏一句话 | 阅读视图选中文字后按 `N`，翻译后默认保存到文末及独立笔记 |
| 编辑模式中使用 | 命令面板，或在 Obsidian 快捷键设置中为 Note Digest 命令指定组合键 |

单字母快捷键不会占用编辑器或输入框中的正常输入。

### Summarize 在哪里？

选中超过 **400 字符**的文字，或跨空行的多个段落，再点击 Digest，侧栏顶部会出现 **Summarize**。点击后总结的是**所选内容**，选区上限为 **12,000 字符**。短词句不会显示这个按钮。

当前尚未实现无需全选的全文摘要、摘要分节导航、翻译本节/全文、原文章内的临时双语显示层，以及完整双语笔记生成。这些属于后续计划，不是安装后已经具备的功能。

## 当前边界

目前只在阅读视图高亮可唯一定位的普通文本段落，不覆盖编辑模式。段落含 `**粗体**`、`*斜体*`、Markdown 链接或行内代码时，源码与渲染文字不同，即使收藏的是同段内另一个普通词，也可能跳过整段高亮。标题、列表、引用、表格、代码块与嵌入内容暂不作为可靠支持范围。原段落被修改或存在无法消歧的重复段落时同样跳过，避免标错位置。高亮未显示不等于收藏丢失，可在侧栏或学习笔记查看记录。

永久插入译文目前限普通单行段落；复杂 Markdown 可先在侧栏阅读。插件运行期间会跟踪来源文件改名或移动，关闭插件期间的移动恢复尚未实现。当前不支持移动端、PDF、图片 OCR、嵌入网页或日语解释。

选词、翻译、插入、收藏与定位的核心流程已有真实 Obsidian 使用反馈，插入括号译文后继续语境解释也已验证。0.2.4 的 69 项自动测试与构建通过；异常恢复、复杂格式等边界仍按[验证清单](docs/TESTING.md)持续检查。

## 隐私与 AI 服务

- 当前 AI 服务为 DeepSeek，用户自行提供密钥；调用可能产生服务商费用。
- 主动翻译、解释或摘要时，发送所选文本及必要的有界上下文到 `api.deepseek.com`，不扫描全库发送。长选区等待点击操作后才发请求。
- 密钥通过 Obsidian SecretStorage 读取；插件数据只保存密钥名称、收藏内容及来源信息，不保存明文密钥。
- 临时 AI 结果不会自动写入 Markdown；点击插入或保存后才写入。收藏元数据保存在仓库插件目录的 `data.json`，可能随用户自己的仓库同步设置同步。
- 插件未实现遥测或自建数据收集服务。发送给 DeepSeek 的数据由其服务条款和隐私政策约束。
