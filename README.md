# Note Digest

**在 Obsidian 原文旁读懂英文，留下语境中的词语和金句。**

Note Digest 是一款独立的 Obsidian 桌面插件。打开仓库里的英文 Markdown 文章，就可以在右侧栏查看中文翻译和全文摘要、结合上下文理解表达，并把值得留下的单词和金句直接保存为学习笔记。当前版本为 **0.3.28 开发版**，支持英文 → 简体中文，采用 [MIT 许可证](LICENSE)。

## 安装

需要 **Obsidian 桌面版 1.11.5 或更新版本**。

### 让 AI Agent 帮你安装

把下面这段话交给能操作本地文件的 AI Agent（例如 Codex 或 Claude Code），让它下载并安装插件。

```text
请帮我安装这个 Obsidian 插件：
https://github.com/jasminemo1110/note-digest

先询问我要安装到哪个 Obsidian 仓库，并确认它的本地路径。
打开 GitHub Releases 列表，选择最新正式版。若只有预发行版（Pre-release），选择最新预发行版。
从同一个版本的 Assets 下载 main.js、manifest.json 和 styles.css。
如果使用 GitHub CLI 下载，请明确指定版本标签。
检查 manifest.json 的版本，将三个文件复制到该仓库的
.obsidian/plugins/note-digest/ 目录，并告诉我如何在 Obsidian 中启用插件。
如果已有旧版，只更新这三个文件，保留 data.json、现有笔记和其他设置。
不要读取、索取或修改 API Key；密钥由我自己在 Obsidian 界面配置。
```

### 从 GitHub Releases 下载安装

1. 打开 [GitHub Releases](https://github.com/jasminemo1110/note-digest/releases)，选中要安装的版本，从其 **Assets** 下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 在目标 Obsidian 仓库中创建 `.obsidian/plugins/note-digest/`，把三个文件放进去。`.obsidian` 是隐藏目录。
3. 在 Obsidian 的 **设置 → 第三方插件 / 社区插件** 中允许使用社区插件，找到并启用 **Note Digest**。如果列表未刷新，重启 Obsidian。
4. 要使用翻译、语境解释或摘要，请按下方步骤[配置 DeepSeek API Key](#配置-deepseek-api-key)。

更新已有安装时，先禁用 Note Digest，下载新版本的三个文件并替换旧文件，保留存有设置和收藏记录的 `data.json`，然后重新启用插件。

### 从源码构建

需要 **Node.js 20+（含 npm）** 和 Git。

```bash
git clone https://github.com/jasminemo1110/note-digest.git
cd note-digest
npm ci
npm test
npm run build
```

构建通过后，把项目根目录的 `main.js`、`manifest.json` 和 `styles.css` 放进目标仓库的 `.obsidian/plugins/note-digest/`，然后按上面的步骤启用插件。

## 配置 DeepSeek API Key

Note Digest 的翻译、语境解释和摘要使用 DeepSeek，需要你自己的 **API Key**。API 调用可能产生费用，请在 DeepSeek 平台查看账户额度与用量。

1. 登录 [DeepSeek 开放平台的 API Keys 页面](https://platform.deepseek.com/api_keys)，创建一个 API Key。可参考 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/api/deepseek-api/)。
2. 打开 Obsidian **设置 → Keychain（密钥链）**，新增一条密钥，取一个方便识别的名称，例如 `deepseek`，将 API Key 填入密钥值并保存。
3. 打开 **设置 → Note Digest**，在 **DeepSeek API Key** 一项中选择刚才保存的密钥。插件使用 Obsidian 的 SecretStorage，只记录密钥名称，不把真实 Key 写入插件的 `data.json`。
4. 打开一篇英文文章，选中一个词并点击 **Digest**。右侧出现中文翻译后，就可以继续点击**语境解释**。

如果提示缺少密钥，请检查 Note Digest 是否选择了正确的密钥；如果提示无权限或额度不足，请检查 DeepSeek 账户和 API Key。不要把 Key 发给 AI Agent、粘贴到 Issue、提交进 Git，或拍进截图。

## 为什么做 Note Digest？

已经存在 Obsidian 里的文章，可以在阅读时直接变成学习材料，无需先搬到浏览器，再导出、导入一遍：

- **阅读不中断**：在原文选词或选句，右侧立即提供翻译入口，并可进一步查看语境解释。
- **学到具体用法**：解释包含音标、当前语境中的含义、用法和双语例句；表达有问题时说明原因并给出建议改法。
- **临时查看或主动留下**：只看翻译不会改动笔记；需要时才把译文放到原文下方或句后括号里。
- **整张解释一起保存**：收藏单词时保留完整解释，金句保留原句和译文，学习区按单词与金句分类。
- **保存到自己的仓库**：可以写到原文末尾、独立学习笔记，或者两者都保存，不需要另外导出 Markdown。
- **回到具体语境**：已收藏内容可在支持的原文段落中高亮，并从侧栏定位来源；同一词在不同语境中分别保留。

## 使用方法

1. 选中一个词、短语或短句，点击浮动的 **Digest**，或在阅读视图按 `D`，即可查看中英对照。也可以划选后直接点右侧栏的 **翻译** 或 **语境解释**。
2. 划选超过 400 字符的文字或跨空行的多个段落时，浮动 Digest 会打开操作栏，等待你选择 **Digest 全文** 或 **Digest 选中段落**。
3. 单词翻译显示原词、音标和含义。英美音标相同时只显示一份，音标和含义各自可以「在选区后加括号」。短语和短句的译文也可「添加到原文下方」。插件确认插入后可继续用原选区查看语境解释。手工修改原文后，请重新划选。
4. 保存位置默认“末尾及独立笔记”，可改为“只有末尾”或“只有独立学习笔记”，统一点击“保存”。语境解释默认保存完整单词卡片，也可选“金句与译文”。翻译模式保存为金句。
5. 阅读视图选中文字后按 N，会翻译并保存金句到末尾及独立笔记；这与新版默认保存位置一致。编辑器、输入框、输入法组合、修饰键或长按不会触发单字母操作。也可通过命令面板或自定义组合快捷键使用。
6. 自然/有效口语表达省略判断模块；错误、不自然表达显示原因与建议改法。语境不足时保留不确定性提示，不编造改法。
7. 新学习笔记与“本文收藏”均区分“单词”“金句”。旧卡片可点击“整理旧版卡片并分组”，只有与旧版输出完全匹配的内容会迁移；手工改动保留。独立学习笔记只在顶部保留一次来源链接。
8. “取消高亮并删除笔记”按记录标记定位，不按单词全文删除。已取消高亮但保留笔记的条目仍可清理；部分失败时显示原因并保留重试入口。新卡片有起止边界，明确属于卡片内部的改动会随卡片删除；旧版无结束边界且手工修改过的卡片会保留，提示手动处理。
9. 仅查看翻译、解释或摘要不会创建学习笔记。段落翻译失败或被新操作取代时，不把未完成结果作为完整翻译保存。

独立学习笔记默认放在 `Digest/文章学习/`，按文章汇总；文件名附有来源 ID，避免同名文章冲突。重复保存不会用新 AI 结果覆盖已有学习卡片或手工修改。

阅读视图和实时预览中的 Markdown 表格可在单个单元格内选词，语境来自该单元格。能核对源码位置时可以选择文末、独立学习笔记或两处。跨单元格、嵌入内容等选区若无法定位，仍可解释并把完整卡片保存到该文章的独立学习笔记。

在 Obsidian 左右侧栏的非编辑文本中也可选中英文，点击浮动的 Digest 或按 `D`。可确认的同段上下文会随选区一起用于理解，译文仍只对应划选内容。结果在 Note Digest 侧栏显示，可以切换翻译、语境解释或选段摘要。

侧栏的语境解释完成后，点击「收藏到独立学习笔记」，可把选中的词、对应原句和完整解释存入 `Digest/侧栏学习笔记.md`。第一次收藏时创建笔记。相同词和原句只保存一次，不同原句各留一张卡。

### 快捷键与入口

| 操作 | 入口 |
| --- | --- |
| 翻译选中的词句 | 悬浮的 Digest 按钮；阅读视图选中文字后按 `D` |
| 查看完整词语解释 | 右侧栏的“语境解释” |
| 快速收藏一句话 | 阅读视图选中文字后按 `N`，翻译后默认保存到文末及独立笔记 |
| 编辑模式中使用 | 命令面板，或在 Obsidian 快捷键设置中为 Note Digest 命令指定组合键 |

单字母快捷键不会占用编辑器或输入框中的正常输入。

### 全文摘要与分节精读

打开 Markdown 文章后，点 Obsidian 左侧的 Note Digest 图标，再点侧栏顶部的 **Digest 全文**。也可以从命令面板运行 **Note Digest: Digest 全文**。插件优先识别 Markdown 标题和访谈问答，其余正文按段落组织。文末独立的 Notes、References、Podcast 等会列在「文末补充」，可单独定位和翻译。

每节最多 **6,000 字符**，每篇最多 **40 节**。正文超过单篇上限时，侧栏先显示本机计算的分篇方案，优先保留完整章节。某章过长时，再按子标题或段落和字数拆分。可以点「从第 1 篇开始」，用「下一篇」继续，也可以展开「查看分篇范围」直接选篇。每次只处理所打开的一篇，摘要可停止并继续。

只想总结一部分时，划选文字后点 **Digest 选中段落**。较短的选区显示概览，较长的可按节摘要，选区上限为 **12,000 字符**。

- **添加到文首**会把当前概览写在笔记属性下方。分篇概览写入时会注明篇号。
- 每节可以**定位原文**或**翻译本节**。译文页逐段显示中英对照，点**返回摘要**可回到刚才的位置。
- 点**将本节译文加入原文**，每段中文会紧跟对应的英文。点**撤销加入译文**，可一次移除这一节已核对的译文。

再次打开相同内容时，有缓存就直接复用。需要新的结果时，可点**重新生成**。

## 与其他 Obsidian 插件联动

Note Digest 可以独立使用，也可以与其他插件配合，把阅读时查到的解释留在原文旁。Claudian 是第一个联动示例。

### Claudian · 追问 Digest 结果

启用 Claudian 后，在 Note Digest 侧栏划选一段译文、语境解释或摘要，点击 **问 Claudian**。所选内容和对应原文会追加到 Claudian 当前对话的输入框。划选全文概览时，草稿会附上文章标题。你可以在「我的追问」下补写问题，再手动发送。

### Claudian · 把聊天问答存为批注

一边读文章一边在 Claudian 提问时，可以把值得回看的解释直接留在相关段落旁。这项联动需要同时启用 Note Digest 和兼容的 Claudian，并打开 Claudian 的主聊天面板。已在 Claudian **2.3.43** 验证。[Claudian 项目](https://github.com/YishenTu/claudian)

1. 在 Markdown 文章的普通正文段落里选中原句，或在编辑模式（含实时预览）把光标放在正文段落或段间空行。
2. 把鼠标移到想保存的已完成回复上，点 **将问答存为批注** 或 **仅答案存为批注**。
3. Note Digest 会在选区或光标所在的段落下插入默认折叠的批注。光标在段间空行时，批注插在那两段之间。标题根据保存的内容生成，例如「单词问答：potential」。点击标题即可展开。

保存与起标题都在本地完成，直接使用已经生成的回复，无需为此配置 DeepSeek 密钥。只装 Note Digest 也可以正常翻译、解释、摘要和收藏。

## 当前边界

阅读视图会高亮能核对源码位置的普通段落和 Markdown 表格单元格。同一个词出现在多个单元格或在同一单元格里重复时，按收藏的原文位置标记。普通段落含粗体、斜体、链接或行内代码等格式时可能跳过高亮。源码变化、渲染与源码不匹配或无法区分的重复内容也可能跳过高亮，收藏仍可在侧栏或学习笔记查看。

永久插入译文支持可准确对应到源码的普通正文段落，包括斜体、粗体、标准 Markdown 链接和多行段落。选中完整链接文字时，括号译文加在链接之后；段落下方的译文在原段结束后另起一段。无法定位的选区保留侧栏译文。插件运行期间会跟踪来源文件改名或移动，关闭插件期间的移动恢复尚未实现。当前不支持移动端、PDF、图片 OCR、嵌入网页或日语解释。

选词、翻译、插入、收藏与定位的核心流程已有真实 Obsidian 使用反馈。超长文章分篇和缓存复用已在 Obsidian 中用模拟请求验证。异常恢复和复杂格式等边界仍按[验证清单](docs/TESTING.md)持续检查。

## 隐私与 AI 服务

- 当前 AI 服务为 DeepSeek，用户自行提供密钥；调用可能产生服务商费用。
- 主动翻译、解释或摘要时，发送所选文本及必要的有界上下文到 `api.deepseek.com`，不扫描全库发送。长选区等待点击操作后才发请求。
- **Digest 全文**按节发送当前文章正文，跳过笔记属性、文首摘要、已加入的分节译文和文末学习区。超长文章的分篇预览在本机完成，开始处理指定篇后才请求对应内容。文末补充可主动请求翻译。
- 密钥通过 Obsidian SecretStorage 读取；插件数据只保存密钥名称、收藏内容及来源信息，不保存明文密钥。
- 在 **设置 → Note Digest → 在本机保留 Digest 结果** 可管理跨重启缓存。开关默认开启，摘要、译文和语境解释缓存在当前设备的当前仓库，最多 **256 条**，序列化上限约 **100 万字符**。达到任一上限时，优先整条移除最久未使用的结果。关闭会清除持久缓存，本次运行中的结果仍可复用。
- 点击插入或保存后才会写入 Markdown。收藏元数据保存在仓库插件目录的 `data.json`，可能随用户自己的仓库同步设置同步。
- 插件未实现遥测或自建数据收集服务。发送给 DeepSeek 的数据由其服务条款和隐私政策约束。
