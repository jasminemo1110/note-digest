# Note Digest 产品方案

状态：2026-11-08 讨论确认。产品名为工作名，公开前查重。

## 用户与目标

用户已把英文文章保存在 Obsidian，希望在原文章中完成阅读、理解、语境学习和积累。无需搬到外部阅读器或导出再导入。

## V1 范围

桌面端，仓库内 Markdown，英文 → 简体中文。优先阅读视图，编辑模式支持选区命令；不包含 PDF、图片 OCR、嵌入网页、移动端和日语规则。

### 阅读界面

当前文章保留为主体。右侧学习栏依次提供「Digest 全文」「Digest 选中段落」「翻译」「语境解释」。后面两个入口使用最新短选区，原文附近也可点击 Digest 或使用阅读快捷键。正文内双语显示和整篇翻译留到后续。

### 临时翻译与原文插入

- 选中英文词语、短语或短句后，翻译在侧栏显示对应中文。需要阅读整段文章时，先 Digest，再翻译本节。
- 阅读结果默认在本次插件运行期间复用。主动插入或收藏后才写入笔记。
- “添加到原文下方”在原段后另起一段，支持多行正文。“在选区后加括号”将译文放在文字节点内；选中标准 Markdown 链接的完整标签时，译文放在链接之后。
- 阅读视图用渲染区段和实际选区偏移定位源码。无法安全定位或预计会改变格式时，在侧栏保留译文。
- 双语阅读层和永久写入相互独立；关闭显示层不删除已经主动保存的译文。

### 长文与摘要

打开文章后可以从侧栏或命令面板发起「Digest 全文」，先看全文概览，再挑小节精读。「Digest 选中段落」对划选范围生成概览或分节摘要。选区覆盖全文时复用全文结果。

摘要以正文为范围，跳过顶部属性、文首摘要、已加入的分节译文和文末学习区。分节优先识别 Markdown 标题和有说话者标记的访谈提问，其余正文按段落组织。文末独立的 Notes、References、附录和 Podcast 等列在「文末补充」，可按需定位和翻译。

侧栏在每节提供「定位原文」和「翻译本节」。本节译文按英文自然段逐一对照，译文页也可定位原文，「返回摘要」回到原来浏览的位置。「将本节译文加入原文」把中文按段放在本节末尾的一个区块中，「撤销加入译文」只移除核对过的生成区块。短词句翻译仍可插入到括号或原段下方。

长文摘要逐节生成，可停止并继续，已取得的分节会复用。概览下方的「添加到文首」将中文写成可折叠区块，位置在笔记属性之后、正文之前。

同一操作、文字和语境已有结果时直接打开。摘要、分节译文、短词翻译和语境解释均可主动「重新生成」。设置中的「在本机保留 Digest 结果」默认关闭，开启后重启 Obsidian 也可复用当前仓库的结果，关闭会清除持久缓存。本机缓存与收藏独立，容量最多 256 项，并有大小上限。

### 语境词条

选词后结合所在句及必要相邻段落解释含义、用法、音标（适用时）、搭配和例句；说明不确定性。保存选中形式、规范词形、解释和原始语境。

语境解释以语境中的词典原形为词头，音标、释义和用法对应词头。例如选中 `Interpreting` 时先解释 `interpret`，另列原文词形，并在语境含义中说明其 -ing 形式及作用。动词（含短语动词）还原基本形式；词汇化形容词和固定表达按实际用法保留，无法可靠判断或整句解释时使用选区原样。文末、独立学习笔记和本文收藏均使用该词头，原文定位、高亮和去重继续依据原始选区。旧收藏不自动改写，重新解释后可主动点击“用本次解释更新”。

完整解释卡片必须保留音标、语境含义、所有返回的用法与例句，以及表达判断和建议改法。明确错误、不够自然、有效的口语/非正式表达和语境不足分别呈现；不把风格差异当作语法错误，不自动替换原文。音标不适用或无法可靠确定时明确说明。

语境解释末尾按需显示“其他常见用法”，最多三条。每条包含词性、简短中文释义及一个双语例句或搭配。仅补充同一词头在日常英语或通用书面语中的高频义项，省略当前义项和偏门用法。收藏完整解释时一并保存。

用户完成语境解释后，可在收藏模块一键把整张卡片追加到文章末尾；独立学习笔记与双目标保存也使用同一份完整内容，不能仅保存中文译文。这里的“所有用法”指卡片生成的全部内容，不宣称穷尽词典义项。

同一来源、同一语境中的同一表达仅收藏一次。不同语境保留各自记录，可关联同词条；V1 不自动合并义项。不同语境出现新义项与当前语境存在歧义分别说明。

### 金句与学习笔记

金句保存原句、中文翻译、来源和可选个人备注。词条和金句均支持：

1. 追加到原文末尾的学习区；
2. 保存到独立学习笔记（默认 Digest/文章学习/）；
3. 两者都保存。

保存目标是显式选择，不因点击 Digest 自动收藏。独立学习笔记按文章汇总所有已收藏词语、金句，可另行生成完整中英对照版本。文件名冲突用稳定来源标识消歧，保留普通 Markdown 可读性。

再次保存同一位置的单词时提示“本词已收藏”。在语境解释结果中点击“用本次解释更新”才会更新已有的卡片副本。插件保留可明确区分的手工备注，遇到手改生成字段或卡片边界不明确时提示冲突。

收藏过的词语和金句在阅读视图中按可确认的原文位置高亮，包括受支持的 Markdown 表格单元格。同一单元格或不同单元格里出现同一个词时，仅标记收藏的那一次。高亮只影响阅读显示，取消收藏后相应高亮消失。

### 原文变化与并发

未变化段落可复用译文；变化段落标记过期，按需重译。请求期间变更原文，旧结果不得应用。保存过的学习记录保留收藏时快照。

原文改名/移动后更新可确认的来源；定位失败时展示原句并明确提示，不能跳转到猜测位置。初期安全策略可以更保守：整篇快照改变即阻止本次插入。

### 隐私与保存

自带 DeepSeek 密钥，通过 Obsidian SecretStorage；仅发送当前请求所需内容。临时结果与永久收藏分离。缓存可后续增加，但不能把临时翻译静默变成学习文档。

不得覆盖用户手改的学习内容。双目标写入可能部分成功，必须逐目标报告并允许幂等重试。

### 插件边栏选区

在 Obsidian 左右侧栏的同一视图中选择可读英文后，可点击 Digest 或按 D。依据工作区视图判断来源。短选区直接翻译，长选区等待选择翻译、语境解释或摘要。主动触发时捕获选区和可确认的同段有界上下文，后续切换解释沿用这份快照。无可确认的语境时按选区处理，译文始终只对应划选内容。

侧栏语境解释提供「收藏到独立学习笔记」，将词语、包含选区的原句和完整解释追加到 `Digest/侧栏学习笔记.md`，无可确认原句时保存实际取得的选区。同词同原句去重，不改写已有卡片。侧栏词卡的唯一保存位置是此笔记。

可编辑控件和 Note Digest 自己的结果面板不作为侧栏来源。独立网页、iframe 或其他独立文档的选区不属于 Obsidian 主窗口的选区。

## V2

日语 → 中文：读音、原形、活用、语法、敬语和义项规则。V1 只预留语言策略，不显示未完成入口。后续再考虑精准单击分词、全文假名与复习功能。

## 验收主线

打开英文 Markdown → 在原文中阅读双语 → 选词解释 → 显式收藏 → 原文高亮 → 文末/独立笔记找到学习内容 → 返回正确来源。临时翻译路径应全程不改笔记。

## 2026-11-08 交互修订

词语卡片顺序为标题、音标、中文译文、精简原始语境、语境含义、用法和新例句，再展示表达判断及纠错。每张卡片去掉重复原词、日期和来源链接；独立学习笔记顶部保留一次来源。显示语境取相关一两句话，超长内容明确省略，不缩减提供给模型的分析语境。

本文收藏中词语和金句均显示双语。阅读视图选中文字后 D 触发 Digest；N 触发翻译并收藏金句。编辑模式使用悬浮按钮、命令面板或自定义组合快捷键。

阅读视图和实时预览支持 Markdown 表格中单个单元格的选区，用该单元格的上下文解释。普通段落、标题、列表和引用按各自渲染块核对原文位置。能确认位置时可保存到文末、独立学习笔记或两处。无法确认位置时，保存入口使用该文章的独立学习笔记，卡片保留可取得的可见语境。源文章未变而文末写入失败时，保存尝试使用该文章的独立学习笔记并显示各目标的结果。

新建的文末学习区将隐藏标记放在「Note Digest 学习笔记」标题下方。用 Outline 把正文拖到学习区上方时，标记留在学习区内。旧版标题上方的标记继续兼容。

已生成 Markdown 不静默迁移；提供显式整理按钮，仅更新能够完全匹配旧版输出的卡片，保留手工改动。

## 0.2.2 侧栏与学习笔记布局

操作栏置顶。短词句默认翻译；长选区先不显示正文、不调用 AI，等待选择 Summarize/翻译/语境解释。暂以超过 400 字符或跨空行段落判为长选区。Summarize 仅覆盖用户所选内容，不声称覆盖全文；保留 12,000 字符选区上限。翻译逐段请求、按本地原文范围配对，显示进度。

翻译模式：英文 → 中文 → 两个插入按钮。解释模式：英文、音标、中文、短语境及详细解释，之后直接进入收藏模块，不提供译文插入按钮。正确自然及有效口语不显示判断模块；有问题时给出原因和建议，语境不足时保留提示。

收藏默认“末尾及独立笔记”，可选“只有末尾”“只有独立学习笔记”，按钮统一“保存”。解释模式提供单词/金句分类，默认完整单词卡片；翻译模式默认金句。N 快捷键同步采用双目标默认。

文末、独立学习笔记以及本文收藏分别以单词、金句副标题分组。已有卡片通过显式整理操作迁移，仅移动可准确匹配的旧生成内容；未知手改内容保持原样。

## 0.2.3 独立删除操作

保留“取消收藏高亮”，新增“取消高亮并删除笔记”。后者检查当前来源文末、对应独立学习笔记及已记录保存路径，按收藏 ID 删除对应卡片，同时取消高亮。既不按词全文搜索，也不删除文章或学习笔记文件。其他语境的同词收藏保持不变。

已经取消高亮但留有笔记的条目继续显示为保留笔记，可使用新按钮清理。两处删除分别报告；部分失败时取消高亮但保留重试入口。新版卡片明确结束边界，其内部手工补充随卡片删除；旧卡片只有在与历史生成格式完全匹配时自动删除，否则说明边界不明确并保留。空分类标题和笔记文件暂保留，不进行额外清理。
