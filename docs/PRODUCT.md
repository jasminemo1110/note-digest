# Note Digest 产品方案

状态：2026-11-08 讨论确认。产品名为工作名，公开前查重。

## 用户与目标

用户已把英文文章保存在 Obsidian，希望在原文章中完成阅读、理解、语境学习和积累。无需搬到外部阅读器或导出再导入。

## V1 范围

桌面端，仓库内 Markdown，英文 → 简体中文。优先阅读视图，编辑模式支持选区命令；不包含 PDF、图片 OCR、嵌入网页、移动端和日语规则。

### 阅读界面

当前文章保留为主体。上方小工具条提供原文/双语、翻译本节、翻译全文及打开侧栏。选区附近提供 Digest 操作，配合可配置快捷键。右侧固定学习栏显示翻译、语境解释及保存操作，收起后仍可继续阅读原文。

### 临时翻译与原文插入

- 选中英文词语、句子或段落后，Digest 在侧栏显示对应中文。
- 默认不添加到原文，也不生成学习文档；关闭会话可丢弃临时结果。
- 用户主动选择“添加到原文”：译文放在所选英文下方，或紧随所选内容的中文括号内。
- 多行/复杂 Markdown 不做括号插入；无法确定安全插入位置时提示重新选择。
- 双语阅读层和永久写入相互独立；关闭显示层不删除已经主动保存的译文。

### 长文与摘要

保留“翻译本节”“翻译全文”。识别为长文后在顶部显示可选 Summarize；初始长文阈值可取 6,000 字符，实际阅读验证后调整。

摘要覆盖全文，以本地段落标识和连续来源范围组织分节。AI 可以建议小节标题与边界，但不能编造原文或遗漏范围；验证不通过则回退到本地按标题/段落分节。用户可从摘要定位原文小节并翻译，不强制先摘要。

长文请求分批、可停止、有进度；保留已完成片段。全文未完成时必须标示部分结果，不导出为“完整全文翻译”。

### 语境词条

选词后结合所在句及必要相邻段落解释含义、用法、音标（适用时）、搭配和例句；说明不确定性。保存选中形式、规范词形、解释和原始语境。

完整解释卡片必须保留音标、语境含义、所有返回的用法与例句，以及表达判断和建议改法。明确错误、不够自然、有效的口语/非正式表达和语境不足分别呈现；不把风格差异当作语法错误，不自动替换原文。音标不适用或无法可靠确定时明确说明。

用户完成语境解释后，可在收藏模块一键把整张卡片追加到文章末尾；独立学习笔记与双目标保存也使用同一份完整内容，不能仅保存中文译文。这里的“所有用法”指卡片生成的全部内容，不宣称穷尽词典义项。

同一来源、同一语境中的同一表达仅收藏一次。不同语境保留各自记录，可关联同词条；V1 不自动合并义项。不同语境出现新义项与当前语境存在歧义分别说明。

### 金句与学习笔记

金句保存原句、中文翻译、来源和可选个人备注。词条和金句均支持：

1. 追加到原文末尾的学习区；
2. 保存到独立学习笔记（默认 Digest/文章学习/）；
3. 两者都保存。

保存目标是显式选择，不因点击 Digest 自动收藏。独立学习笔记按文章汇总所有已收藏词语、金句，可另行生成完整中英对照版本。文件名冲突用稳定来源标识消歧，保留普通 Markdown 可读性。

收藏过的词语/金句在原文阅读视图自动高亮，定位到具体语境而非全文同词匹配。高亮为显示效果，不默认往原文写 == 标记；取消收藏后相应高亮消失。

### 原文变化与并发

未变化段落可复用译文；变化段落标记过期，按需重译。请求期间变更原文，旧结果不得应用。保存过的学习记录保留收藏时快照。

原文改名/移动后更新可确认的来源；定位失败时展示原句并明确提示，不能跳转到猜测位置。初期安全策略可以更保守：整篇快照改变即阻止本次插入。

### 隐私与保存

自带 DeepSeek 密钥，通过 Obsidian SecretStorage；仅发送当前请求所需内容。临时结果与永久收藏分离。缓存可后续增加，但不能把临时翻译静默变成学习文档。

不得覆盖用户手改的学习内容。双目标写入可能部分成功，必须逐目标报告并允许幂等重试。

## V2

日语 → 中文：读音、原形、活用、语法、敬语和义项规则。V1 只预留语言策略，不显示未完成入口。后续再考虑精准单击分词、全文假名与复习功能。

## 验收主线

打开英文 Markdown → 在原文中阅读双语 → 选词解释 → 显式收藏 → 原文高亮 → 文末/独立笔记找到学习内容 → 返回正确来源。临时翻译路径应全程不改笔记。

## 2026-11-08 交互修订

词语卡片顺序为标题、音标、中文译文、精简原始语境、语境含义、用法和新例句，再展示表达判断及纠错。每张卡片去掉重复原词、日期和来源链接；独立学习笔记顶部保留一次来源。显示语境取相关一两句话，超长内容明确省略，不缩减提供给模型的分析语境。

本文收藏中词语和金句均显示双语。阅读视图选中文字后 D 触发 Digest；N 触发翻译并将金句存到原文末尾，同时显示在本文收藏并高亮。编辑模式不占用单字母；可通过命令面板或自定义组合快捷键使用。其他保存目标继续通过侧栏选择。

已生成 Markdown 不静默迁移；提供显式整理按钮，仅更新能够完全匹配旧版输出的卡片，保留手工改动。

## 0.2.2 侧栏与学习笔记布局

操作栏置顶。短词句默认翻译；长选区先不显示正文、不调用 AI，等待选择 Summarize/翻译/语境解释。暂以超过 400 字符或跨空行段落判为长选区。Summarize 仅覆盖用户所选内容，不声称覆盖全文；保留 12,000 字符选区上限。翻译逐段请求、按本地原文范围配对，显示进度。

翻译模式：英文 → 中文 → 两个插入按钮。解释模式：英文、音标、中文、短语境及详细解释，之后直接进入收藏模块，不提供译文插入按钮。正确自然及有效口语不显示判断模块；有问题时给出原因和建议，语境不足时保留提示。

收藏默认“末尾及独立笔记”，可选“只有末尾”“只有独立学习笔记”，按钮统一“保存”。解释模式提供单词/金句分类，默认完整单词卡片；翻译模式默认金句。N 快捷键同步采用双目标默认。

文末、独立学习笔记以及本文收藏分别以单词、金句副标题分组。已有卡片通过显式整理操作迁移，仅移动可准确匹配的旧生成内容；未知手改内容保持原样。
