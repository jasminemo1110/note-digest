# 开发路线图

## P0 — 项目与契约

- [x] 独立项目、产品方案、架构边界、验证流程。
- [ ] 插件构建、右侧栏、设置与语言扩展接口。

## P1 — 选区 Digest 与安全插入（首个开发增量）

- [ ] 阅读视图和编辑器获取选区及有界语境。
- [ ] 侧栏翻译、语境解释、加载/失败/过期状态。
- [ ] SecretStorage + DeepSeek，结构及长度校验。
- [ ] 译文插入下方或括号；变更和歧义定位保护。
- [ ] 自动测试、类型检查、构建。
- [ ] 真实 Obsidian 与实际 provider 验证。

## P2 — 收藏与学习汇总

- [ ] 来源身份、来源移动和改名处理。
- [ ] 同语境去重，跨语境保留；词条与金句模型。
- [ ] 文末、独立笔记、双目标保存；部分失败与幂等重试。
- [ ] 原文语境高亮及取消收藏。
- [ ] 用户手工修改保护，按文章汇总全部收藏。

## P3 — 长文阅读

- [ ] 阅读工具条及原位双语显示层。
- [ ] 本地段落模型、标题分节与变化检测。
- [ ] 长文顶部 Summarize，来源覆盖校验、摘要定位与按节翻译。
- [ ] 翻译本节/全文，分批、停止、进度与失败恢复。
- [ ] 完整双语笔记生成，部分结果明确标识。

## P4 — V1 验证与交付

- [ ] 独立测试仓库端到端验证，主题/插件重载/多窗口检查。
- [ ] 收藏恢复、文件重命名、重复原句、Markdown 结构回归。
- [ ] README、隐私说明、安装包与来源致谢。
- [ ] 插件名称查重；公开仓库与发布另行获得用户授权。

## V2 — 日语

语言策略已预留，日语读音、活用、语法与义项规则待设计和测试。V1 不以语言枚举存在作为已支持的承诺。
