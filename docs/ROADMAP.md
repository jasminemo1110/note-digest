## P2 — 收藏与学习汇总

- [x] 本地稳定来源身份，插件运行期间跟踪来源文件/目录改名和移动。
- [x] 同语境去重，跨语境保留；词条与金句模型。
- [x] 文末、独立笔记、双目标保存；部分失败与幂等重试。
- [x] 阅读视图普通段落的原文语境高亮及取消收藏高亮。
- [x] 用户手工修改保护，按文章汇总全部收藏。
- [x] 一键将完整语境解释卡片追加文末：音标、含义、全部用法、例句、表达判断与建议改法；独立笔记同样完整保留。

0.2.0 为本地开发版：36 项自动测试及构建通过；真实 Obsidian 收藏/高亮流程待验证。已写入笔记不会因取消收藏被删除。高亮只作用于可精确对应的普通段落；复杂格式、相同段落歧义或原段落变化时跳过。

- [ ] 0.2.0 真实 Obsidian 三目标保存、高亮和重载验证。
- [ ] 富 Markdown 高亮支持；插件关闭期间的离线移动恢复。

## P3 — 长文阅读

- [ ] 阅读工具条及原位双语显示层。

- [ ] 完整双语笔记生成，部分结果明确标识。

- [ ] 插件名称查重；公开仓库与发布另行获得用户授权。
