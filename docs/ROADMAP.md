## 下一步 — 精读与复习

1. **点高亮打开学习卡。** 在阅读视图点击已收藏的单词或金句，按原文位置打开对应卡片，直接读取已保存的译文或解释。用一篇含重复词语的文章验证同词不同语境的卡片能分别打开，并在 HiLighter 同时开启时检查选区菜单与点击行为。
2. **正文内双语展开。** 从分节摘要定位到正文时，在阅读视图临时展开或收起对应段落的现有译文。后续再扩展到全文翻译、完整双语笔记和 V1 发布回归。 [Interlinear 的逐段双语与揭译交互](https://github.com/linyp/obsidian-interlinear)

**验收场景**

读到 “The report glosses over the main trade-off.” 时查看译文，再解释并收藏 `gloss over`。重读时点击这次出现的高亮，看到当时保存的释义和原句。

### 待评估交互

- **按阅读意图用颜色。** 先试一种“待查难句”标记，读完从“本文收藏”集中查看，再逐条决定是否解释和正式收藏。根据使用频率决定是否增加颜色、名称或筛选。 [HiLighter](https://community.obsidian.md/plugins/hilighter)
- **快速看译文，再深入解释。** 评估贴近选区的简短译文预览。用单词、多词短语和同词不同语境样例，对比查看释义、保存语境和回到原文的操作步数、耗时与释义质量。 [Mini Translator](https://community.obsidian.md/plugins/mini-translator) · [AI Translation Assistant](https://community.obsidian.md/plugins/ai-translator-by-taoye)
- **HiLighter 联动。** 有实际跨插件需求时，先用单张卡的 Markdown 导出验证“导出 → 语境解释 → 主动收藏”，检查原句、来源和备注能保留到什么程度。验证后再评估共用高亮或双向同步。 [HiLighter 导出说明](https://community.obsidian.md/plugins/hilighter#changelog)
